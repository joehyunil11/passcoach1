# 공무원 AI (9급 공무원 시험 대비 학습 앱)

9급 공무원 시험 준비생을 위한 AI 문제풀이 학습 플랫폼의 **메인 홈 화면**입니다.
별도의 빌드 도구나 프레임워크 없이 HTML · CSS · 바닐라 JavaScript로만 구현했습니다.

## 실행 방법

`시작.bat`을 두 번 누르면 서버가 켜지고 브라우저가 `http://127.0.0.1:5501/index.html`로 자동 열립니다.
`index.html`을 직접 열어도, 서버가 켜지는 순간 같은 주소로 자동 이동합니다.

직접 실행하려면 아래와 같이 합니다. **AI 선생님**이 ChatGPT 정답을 말하려면 OpenAI API 키가 필요합니다.

```bash
copy .env.example .env
# .env 에 OPENAI_API_KEY=sk-발급받은키 를 넣습니다. https://platform.openai.com/api-keys
node server.js
```

이후 `http://127.0.0.1:5501` 접속. 키를 서버에 넣지 않았다면, AI 선생님 화면의 **ChatGPT 연결**에서 브라우저에만 저장할 수도 있습니다. ChatGPT 웹 로그인과는 다릅니다.

## 구현된 기능

| 영역 | 내용 |
| --- | --- |
| 사이드바 | 데이터 기반 메뉴 렌더링, 활성 메뉴 표시, 상단바 제목 자동 변경 |
| 과목 카드 | 5종 과목 + AI 유사문제 강조 카드, 클릭 시 해당 과목 문제 풀이로 이동 |
| 학습 도구 | AI 질문 · 학습기록 · 오답노트 · 이용권 카드 (색상 액센트) |
| 문제 풀이 | 과목별 10문항, 진행률 · 남은 시간 표시, 채점 결과 시트 |
| 즉시 채점 | 답을 고르는 순간 `정답입니다!` / `틀렸습니다` 메시지와 정답 표시, 해당 문항 잠금 |
| AI 해설 패널 | 문제 아래에 정답 · 핵심 개념 · 자세한 해설 · 오답 분석 · 시험장 포인트 표시 |
| 해설 탭 | `AI 해설` · `핵심 정리` · `오답 분석` · `유사 문제` 4개 탭 전환 |
| 유사 문제 | 같은 단원 문제를 우선 추천하고 `바로 풀기`로 해당 문항으로 이동 |
| 오답노트 | 틀린 문제를 브라우저에 자동 저장, 과목 필터 · 틀린 날짜 · 전체 삭제 제공 |
| 다시 풀기 | 오답노트에서 해당 과목의 그 문항으로 바로 이동, 정답을 맞히면 목록에서 자동 제거 |
| 학습기록 | 답을 고른 순간 영역별 푼 문항·정답률이 저장되고, 과목 탭으로 조회 |
| 나의 성적 | 과목 전체 푼 문항 수와 정답률을 표로 표시 |
| 마스코트 | 인라인 SVG 로봇 캐릭터 + 말풍선, 부드러운 플로팅 애니메이션 |
| AI 선생님 | 질문을 ChatGPT(OpenAI)에 보내 9급 과목 정답·해설을 받아 옴 |
| 반응형 | 1200 / 1080 / 980 / 900 / 860 / 660 / 620 / 420px 브레이크포인트, 모바일 드로어 |
| 한 화면 구성 | 1366×660 이상에서 스크롤 없이 전체 표시 (과목 6종 1행 배치) |
| 접근성 | 스킵 링크, `aria` 속성, 키보드 포커스 링, `prefers-reduced-motion` 대응 |
| 단축키 | `1`~`4` 선택지 선택, `←`/`→` 문제 이동, `Esc` 모바일 메뉴 · 결과 닫기 |

## 커스터마이징

- **색상 / 간격**: `css/base.css` 최상단 `:root` 변수만 수정하면 전체 테마가 바뀝니다.
- **과목 추가**: `js/data.js`의 `SUBJECTS` 배열에 항목을 추가하면 카드가 자동 생성됩니다.
- **메뉴 추가**: `NAV_GROUPS`에 항목을 추가하고 `ICONS`에 SVG path를 등록합니다.
- **문제 추가**: `js/questions.js`의 과목별 `questions` 배열에 문항을 추가합니다.
- **해설 추가**: `js/explanations.js`에서 같은 과목·같은 순서에 항목을 추가합니다.
  `wrong`의 키는 선택지 인덱스(0부터)이며, 비워 두면 기본 문구가 대신 표시됩니다.
